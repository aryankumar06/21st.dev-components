## 2024-05-24 - Accessibility and Tooltips on Icon-Only Buttons
**Learning:** Icon-only buttons must explicitly declare both `aria-label` (for screen readers) and `title` (for visual tooltips). In Shadcn/Lucide setups, icons don't inherently communicate their action to either assistive technologies or sighted users needing clarification. Missing these attributes is a common accessibility trap in dense UIs like habit trackers.
**Action:** Always add both `aria-label` and `title` attributes to icon-only buttons as a standard procedure to ensure an inclusive and intuitive user experience.

## 2026-08-04 - Keyboard Accessibility on Hidden File Inputs
**Learning:** Hiding `<input type="file">` elements using `display: none` within custom styled `<label>` wrappers breaks native keyboard accessibility for file uploads. Users navigating via keyboard cannot focus the input or trigger the upload dialog. Furthermore, when adding an `onKeyDown` event handler to a wrapper element (like a `<label>`) that might contain nested interactive elements (like a "Remove file" button), keyboard events from those children will bubble up and unintendedly trigger the parent's handler unless mitigated.
**Action:** When hiding a file input, always ensure its parent wrapper (e.g., `<label>`) is keyboard accessible by adding `tabIndex={0}`, visible focus states (`onFocus`/`onBlur` setting styles like `box-shadow`), and an `onKeyDown` handler to trigger the nested file input via Enter/Space. Critically, include `if (e.target !== e.currentTarget) return;` in the wrapper's `onKeyDown` handler to prevent event bubbling from mistakenly triggering the upload when users interact with nested buttons.
## 2026-08-09 - Empty States for Filtered Views
**Learning:** When implementing empty states for data-heavy components triggered by active filters or search queries, always include an actionable 'Clear filters/search' button to speed up user recovery and prevent dead-ends.
**Action:** Always include a 'Clear filters/search' button when an empty state is caused by active filters or search.
